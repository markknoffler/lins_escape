# ☁️ Lin's Escape — A Handcrafted Sanctuary for Talinbon

> *"I'm good at something, will make something nice for you using those skills, just give me some days... Pinky promise!"*
> — October 13, 2026

**Lin's Escape** is a dedicated, interactive digital sanctuary created by Samreedh for **Talinbon (Lin)**. Designed as a haven away from demanding medical school hospital postings, strict hostel curfews, clinical vivas, and daily pressures, this space offers warmth, calming interactive worlds, soft lo-fi ambiance, and thoughtful reminders.

---

## 🌟 Key Features

1. **Interactive Living Worlds**:
   - **Cozy CLOY & Goblin Café**: Warm hearth, cat petting interaction, gentle rain, fresh chai, and comforting OST vibes.
   - **Sunset Ocean Shore**: Pastel golden hour tide, origami worry boats, and soothing ocean acoustics.
   - **Umrangso & Karbi Starlit Peak**: Whispering pine mist, turquoise waters, and crackling campfire embers under the northern stars.
   - **Midnight Neon Seoul**: Rain-slicked streets, lo-fi beats, steaming hot momos, and late-night calm with zero alarm clocks.
   - **Blossom & Melody Meadow**: Wildflowers, acoustic guitar, and colorful crochet yarn where art blooms freely.

2. **Personalized Emergency Care Kit**:
   - **12 Observant Stationery Letters**: Touching notes celebrating her medical journey at DMCH, her 11/10 singing voice, the Umrangso road trip bet, her Spider-Man crochet skills, and reassurance for late-night insomnia.
   - **Hostel Fortune Cookie**: Whimsical fortunes grounded in real inside jokes and affectionate banter.
   - **Cathartic Stress Yeeter**: Toss clinical postings, substitute drama, and hospital fatigue into a black hole or feed them to the cat.
   - **Hostel Tea Kettle Timer & Bubble Wrap**: Calming micro-breaks to reset during long study nights.

3. **Built with**:
   - React 19 + TypeScript
   - Vite 8
   - Tailwind CSS
   - Three.js & Framer Motion
   - Web Audio Sound Synthesis Engine

## 🚀 Deployment & Local Development

```bash
# Install dependencies
npm install

# Run locally in development mode
npm run dev

# Build for production
npm run build
```
